Design system

Foundations and components for Vento's ten modules. Colour carries status or action only — never decoration. Every money value uses tabular figures.

Colour

Brand violet #7677FB for focus rings, selection and charts. Buttons and links use the deeper #5B5CE0: white text on #7677FB is only 3.6:1, on #5B5CE0 it passes AA at 5.2:1.
